Developer Integration Guide

How to use this endpoint to fetch clean webpage source content for AI applications, RAG pipelines, and Agents.

1. POST Request (Recommended for Batch) POST /api/extract

Send a JSON payload with an array of URLs. The API processes them in parallel (max 40) using a 3-tier fallback system with IP spoofing to bypass bot protection.

// Node.js Example (Fetch)
const response = await fetch('https://your-vercel-domain.vercel.app/api/extract', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    urls: [
      "https://en.wikipedia.org/wiki/Artificial_intelligence",
      "https://react.dev"
    ]
  })
});

const data = await response.json();
console.log(data.results[0].contentForAI); // Access AI-formatted text
2. Python Integration (Requests) POST /api/extract 
import requests

url = "https://your-vercel-domain.vercel.app/api/extract"
payload = {
    "urls": ["https://indianexpress.com/", "https://www.aajtak.in/"]
}

response = requests.post(url, json=payload)
data = response.json()

# Feed directly to LangChain, LlamaIndex, or OpenAI
for result in data.get('results', []):
    if result.get('contentAvailable'):

Why use contentForAI?

The returned JSON includes a standard pageContent field, but specifically includes a contentForAI field. This field prepends the Source URL, Title, and Extraction Status in a structured plain-text format perfectly optimized for injecting into LLM context windows (like GPT-4 or Claude 3) without requiring additional prompt engineering to establish context.
